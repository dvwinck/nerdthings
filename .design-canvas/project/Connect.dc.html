nerdquotes
Characters Quote of the day Use with MCP

Use it from your AI agent

Nerd Quotes is also a remote MCP server. Add one URL to any MCP client. Nothing to install, no key, no sign-up.

Server URL

https://[YOUR-DOMAIN]/mcp

Add it to a client

Claude Code

claude mcp add --transport http nerdquotes https://[YOUR-DOMAIN]/mcp

Any client with a JSON config

{
  "mcpServers": {
    "nerdquotes": {
      "url": "https://[YOUR-DOMAIN]/mcp"
    }
  }
}

Tools

ToolArgumentsReturns
random_quoteblock optional, e.g. startrekOne quote, from any block or from the one you name
quote_of_the_daynoneToday’s quote, the same for everyone, changes at 00:00 UTC
quotes_by_charactercharacter, e.g. spockEvery quote from that character
list_blocksnoneThe blocks and how many quotes each has
list_charactersblock optionalCharacters, their ids and quote counts

Plain JSON API

The same five things, as GET requests.

GET /api/random?block=startrek
GET /api/today
GET /api/characters/spock
GET /api/blocks
GET /api/characters?block=startrek

Every quote looks like this

{
  "id": "startrek-spock-live-long-and-prosper",
  "text": "Live long and prosper.",
  "character": { "id": "spock", "name": "Spock" },
  "block": "startrek",
  "source": {
    "title": "Star Trek: The Original Series",
    "episode": "Amok Time",
    "year": 1967
  }
}
